# FS-Project1

# Micro CRM Leads
A simple micro-CRM application built for coursework, with an Express backend and static frontend.

# Demo
Deployed at Render
https://fs-project1.onrender.com/

# Features
Lightweight CRM for managing leads
Express.js backend API
Static frontend (index.html / app.js)
Deployable for Render or local
Easy to extended for future needs

# Local setup to run 
1. Clone the repository (git clone https://github.com/asiego/FS-project1)
2. Install dependencies (npm install)
3. Run the server (npm start)
4. Dev mode (npm dev)

# Reflection

Now after the project it feels like I understand a little more once again and could put some of that theoretical knowledge into practice. Frontend has always been easier to me so projects like these where the frontend is simple and the focus is on the backend really suit my learning and the growth of my skills from pure frontend to fullstack.

I find it easy to understand the logic behind working on projects like and how the front and backend come together but the hard part for me is the actual writing of the code and understaning it together with the syntax. The importance of file management and folder structures has also now been ingrained in my brain now after having some deployment problems with  some misplaced files.  

Overall I feel like I learned some new tricks again and gained some confidence in planning, developing and delivering a working application. Overall I gained a deeper understanding of backend develompent and deployment. Even if this project was on the simpler side it will support my learning and build fundamental skills for upcoming projects and coursework.

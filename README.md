# FS-Project1

# Micro CRM Leads
A simple micro-CRM application built for coursework, with an Express backend and static frontend.

# Demo
Deployed at Render
https://fs-project1.onrender.com/

# Features
* Lightweight CRM for managing leads

* Express.js backend API

* Static frontend (index.html / app.js)

* Deployable for Render or local

* Easy to extended for future needs

# Local setup to run 
1. Clone the repository (git clone https://github.com/asiego/FS-project1)
2. Install dependencies (npm install)
3. Run the server (npm start)
4. Dev mode (npm dev)

# Reflection
Working on this project was once again mostly a learning experience, going into this I had a very basic understanding of any server-side development. Now after studying all the material it feels like I understand a little more of it. Just like the workshops I could again and could put some of that theoretical knowledge into practice. Frontend has always been easier to me so projects like these where the frontend is simple and the focus is on the backend really suited my learning and the growth of my skills from pure frontend to fullstack.

I find it easy to understand the logic on projects like these and how the front and backend come together but the hard part for me is the actual writing of the code and understanding it together with the actual syntax. The importance of file management and folder structures has also now been ingrained in my brain now after having some deployment problems with misplaced files.   

Overall I feel like I learned some new tricks again and gained some confidence in planning, developing and delivering a (somewhat) working application. Overall I gained a little deeper understanding of backend develompent and deployment and some motivation to do better than this on next projects. 

I feel like this project deserves maybe 12/20 points in the rubric minus the points for late submission.
